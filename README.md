# Brewlog — Coffee Rating App

A premium, animated coffee discovery and rating experience built with HTML, CSS, JavaScript, Node.js and Express.

## Features

- Cinematic coffee-inspired UI
- Responsive desktop/mobile layout
- Animated hero coffee cup and steam
- Floating glassmorphism UI
- Interactive 5-star rating
- Taste, aroma and presentation sliders
- Dynamic coffee cards
- Community reviews
- Rating analytics chart
- Animated statistics
- Express REST API
- JSON-based persistence
- CORS enabled

## Run

### 1. Install Node.js
Install Node.js LTS if it is not already installed.

### 2. Open terminal in this project folder

```bash
npm install
```

### 3. Start the backend

```bash
npm start
```

### 4. Open

http://localhost:3000/Frontend/index.html

The frontend also contains fallback demo data, so the visual UI remains usable if the API is unavailable.

## API

GET `/api/coffees`
GET `/api/reviews`
GET `/api/stats`
POST `/api/reviews`
DELETE `/api/reviews/:id`

## Design

Dark espresso palette, warm accent lighting, editorial typography, glassmorphism, micro-interactions, responsive cards, animated statistics and chart-based analytics.
